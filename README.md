# Student Performance Predictor

Predicts whether a student will pass from study hours, attendance, previous score and sleep, using a Decision Tree whose rules are printed in plain text.

## What you'll learn

- Decision Trees
- Readable rules with export_text
- Controlling overfitting with max_depth

## How to run

```bash
git clone https://github.com/Ddharsh1707/student-performance-predictor.git
cd student-performance-predictor
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
